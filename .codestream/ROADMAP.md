# Roadmap

Milestones in order. Each one is a vertical slice — something a user can run.

**How to keep this file useful:** a milestone states a user-visible outcome, never
a layer. "Types for the ledger" is not a milestone; "you can record a transfer and
both balances move" is. If you can't name what a person can do at the end, it
isn't ready to be a milestone.

The phase estimate is a guess. When it changes, change it — or drop the count.
A stale count is worse than no count.
